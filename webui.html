🔤 常用元字符

表达式说明示例
\d任意数字文件_\d+ 匹配 文件_123
\w字母/数字/下划线\w+ 匹配 名称
\s空白字符（空格/制表）\s+ → 空格合并
.任意字符（除换行）a.c 匹配 abc/adc
^行首^IMG 以 IMG 开头
$行尾.jpg$ 以 .jpg 结尾
[abc]字符集[0-9] 匹配数字
[^abc]取反字符集[^0-9] 非数字
|或jpg|png 匹配 jpg 或 png
( )分组捕获(abc)+ 匹配 abcabc

🔁 量词

量词含义
*0 次或多次（\d*）
+1 次或多次（\d+）
?0 次或 1 次（colou?r）
{n}恰好 n 次（\d{4} = 4位数字）
{n,}至少 n 次
{n,m}n 到 m 次

💡 场景速查（替换为 $1 表示第 1 组）

  • 去数字后缀：查找 \d+$ → 替换 (空)，IMG_0012.jpg → IMG_.jpg
  • 空格转下划线：查找 \s+ → 替换 _，my photo → my_photo
  • 提取括号内容：查找 \(([^)]*)\) → 替换 $1，照片(生日).jpg → 照片生日.jpg
  • 去前导零：查找 ^0+ → 替换 (空)，007.jpg → 7.jpg
  • 删除中文括号：查找 [（）] → 替换 (空)
  • 连续空格合并：查找 \s+ → 替换

正则作用于生成后的新文件名（先编号 → 再正则处理）。查找内容留空时正则不启用。
替换为 $1、$2 可引用分组捕获的内容。

📋 操作日志
📖 使用说明 完整操作指南

🚀 快速开始（四步完成批量重命名）

1添加文件夹：点击左侧「📂 浏览」选择目标文件夹，或直接手动输入路径后回车；支持多个文件夹，可勾选「递归子目录」「仅文件夹」「过滤系统文件」（默认开启，隐藏文件/desktop.ini 等不会出现在列表里）
2加载文件列表：点击「⟳ 加载选中文件夹」（只加载当前高亮的文件夹，点击列表中的文件夹可切换选中，双击或回车立即加载）；需要加载全部文件夹时点「加载全部」
3设置命名规则并生成预览：在「基本功能」设置前缀/编号等规则，点击「👁 生成预览」核对新文件名；确认无误后再操作。注意「生成预览」按钮会随标签页变化——在「AI 内容命名」页点击等于再跑一轮 AI（云端模式会消耗额度），规则预览请在其他页点
4开始重命名：按钮上会显示将影响的文件数；没生成预览时会先弹确认。执行真实磁盘操作，出错可点「↩ 撤销」一键恢复（撤销按钮在没有可撤销记录时是灰的）

✏️ 命名规则说明

  • 前缀 + 编号：`旅行_01.jpg`、`旅行_02.jpg`（推荐）
  • 编号 + 前缀：`01_旅行.jpg`、`02_旅行.jpg`
  • 前缀 + 编号 + 后缀：`旅行_01_备份.jpg`
  • 分类 + 编号：勾选「按分类命名」后，按图片识别结果分类编号：`人物_01`、`风景_02`
  • 编号位数可自定义：输入 1-20 的任意数字，`1` 表示不补零（`旅行_1`、`旅行_2`…）；编号按「加载顺序（默认文件名排序）」依次分配，与表格里临时排序无关
  • 功能开关：「命名规则设置」「添加&替换」各有「启用」勾选框，编号功能有独立开关，默认全部勾选；取消勾选后预览与重命名只应用勾选的功能
  • 修改扩展名：在「修改扩展名」里填 `md` / `.md` / `.tar.gz` 等可统一改扩展名（留空则保持原扩展名；无扩展名的文件也能加上）；Excel 导入映射里的新文件名同样可以带不同扩展名
  • 元数据占位符：前缀可插入 `{创建日期}` `{修改日期}` `{文件大小}` `{文件扩展名}` `{ID:3}` 等占位符

🔧 高级功能

  • 添加内容：在文件名前/后统一插入文字（受「添加&替换」开关控制）
  • 查找替换：批量替换文件名中的指定文字，三种查找方式：包含（替换所有出现）、开头是（文件名以目标开头，仅替换靠前的那个）、结尾是（文件名以目标结尾，仅替换靠后的那个）
  • 正则替换：在「正则替换」页使用正则表达式（留空即不启用），如 `\d+` 去除数字、`\s+` 空格转下划线
  • 模板管理：保存/加载常用规则模板，模板存储于 `data/templates/`
  • 导出 Excel：将重命名清单导出为 xlsx（原文件名/新文件名/状态/分类/所在文件夹）

🖼️ 图片内容识别（4 种模式）

  • ⚙️ 规则分类：按扩展名自动分类（图片/文档/压缩包/视频/音频），无需联网
  • 🖥 本地 CLIP：自动使用 `resources/model_pack` 离线模型，识别内容语义（人物/动物/风景…）
  • 🦙 Ollama 多模态：连接本机 Ollama 视觉模型（如 minicpm-o、qwen2.5vl），点「🔍 检测并接入已有模型」自动发现
  • ☁️ 云端 AI API：支持 OpenAI / DeepSeek / 智谱 GLM / 通义千问 / 硅基流动 / 腾讯混元 / 自定义 7 种服务商，填入 API Key 后点「🔗 测试连接」验证
  • 分类模式支持固定分类 / 自定义分类 / AI 自由识别（描述、标题、多标签）

🤖 AI 内容命名

  • 根据文件内容智能生成文件名，支持 txt / md / pdf / docx / xlsx / pptx / zip / epub 等格式
  • 两种模式：☁️ 云端 API（需 Key）或 🦙 本地 Ollama（自动检测模型）
  • 可自定义提示词（`{filename}`、`{content}` 占位符）、内容长度限制、批量统一风格
  • 批量生成过程中可随时点「⏹ 停止生成」，立即生效并保留已完成结果
  • AI 页点「👁 生成预览」即触发 AI 命名，点「▶ 开始重命名」按 AI 名字执行，不会被命名规则覆盖

⌨️ 快捷键

Ctrl+O 选择文件夹 Ctrl+Z 撤销重命名（在输入框里打字时不触发）

Ctrl+R 是浏览器刷新，本程序不再占用，避免误触批量改名。

⚠️ 注意事项

⚠️ 请务必备份重要文件后再操作！
· 重命名是真实的磁盘操作，执行后可通过「撤销」恢复最近一次操作
· 云端 AI 识别需要有效的 API Key，识别失败时会在状态栏显示原因
· Ollama 首次加载视觉模型可能需要较长时间
· 撤销日志保存在 `data/_undo_logs/`，与桌面版兼容
· AI 配置（含 API Key）保存在 `data/ai_config.json`，请勿外泄
